# Create a Changelog Entry

Review the currently uncommitted changes in this repo and think hard about what has been done to create a comprehensive summary for use in a changelog, and then add that comprehensive changelog to ./CHANGELOG.md as the top entry above the previous entry. For your entry heading, use the current date and time in format YYYY-MM-DD hh:mm (use 24 hour clock for hours segment) and a short title that summarizes your entry. Format your entry in whatever way makes sense for the tasks that have been completed. Be thorough and include all relevant details.
